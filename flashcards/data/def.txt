Hopningspunkt;$\text{Givet en mängd } M \subset \mathbb{R}^n \text{ så säger vi att } \bar{x} \in \mathbb{R}^n \text{ är en hopningspunkt till } M \text{ om det för varje } \delta > 0 \text{ finns en punkt } \bar{y} \in M \setminus \{\bar{x}\} \text{ sådan att } |\bar{x} - \bar{y}| < \delta.$
Gränsvärde i en punkt;$\text{Låt } \bar{f} : D_{\bar{f}} \to \mathbb{R}^m \text{ där } D_{\bar{f}} \subset \mathbb{R}^n, \text{ och antag att } \bar{a} \text{ är en hopningspunkt till } D_{\bar{f}}. \text{ Vi säger då att } \bar{f} \text{ har gränsvärde } \bar{b} \in \mathbb{R}^m \text{ i } \bar{a} \text{ om det för varje } \varepsilon > 0 \text{ finns } \delta > 0 \text{ sådant att } |\bar{x} - \bar{a}| < \delta \text{ och } \bar{x} \in D_{\bar{f}} \setminus \{\bar{a}\} \Rightarrow |\bar{f}(\bar{x}) - \bar{b}| < \varepsilon. \text{ Vi skriver i så fall } \lim_{\bar{x} \to \bar{a}} \bar{f}(\bar{x}) = \bar{b}.$
Gränsvärde i oändligheten;$\text{Antag att } \bar{f} : D_{\bar{f}} \to \mathbb{R}^m \text{ där } D_{\bar{f}} \subset \mathbb{R}^n, \text{ och att det för varje } R > 0 \text{ finns punkter } \bar{x} \in D_{\bar{f}} \text{ med } |\bar{x}| > R. \text{ Om } \bar{b} \in \mathbb{R}^m \text{ uppfyller att för varje } \varepsilon > 0 \text{ finns } R > 0 \text{ så att } |\bar{f}(\bar{x}) - \bar{b}| < \varepsilon \text{ för alla } \bar{x} \in D_{\bar{f}} \text{ med } |\bar{x}| > R, \text{ så säger vi att } \bar{f}(\bar{x}) \text{ har gränsvärde } \bar{b} \text{ då } |\bar{x}| \to \infty \text{ och skriver } \lim_{|\bar{x}| \to \infty} \bar{f}(\bar{x}) = \bar{b}.$
Kontinuitet;$\text{Om } \bar{f} : D_{\bar{f}} \to \mathbb{R}^m \text{ (} D_{\bar{f}} \subset \mathbb{R}^n \text{) och } \bar{a} \text{ ligger i } D_{\bar{f}}, \text{ då sägs } \bar{f} \text{ vara kontinuerlig i } \bar{a} \text{ om antingen: } \bar{a} \text{ inte är en hopningspunkt till } D_{\bar{f}}, \text{ eller } \lim_{\bar{x} \to \bar{a}} \bar{f}(\bar{x}) = \bar{f}(\bar{a}). \text{ Om } \bar{f} \text{ är kontinuerlig i alla punkter i } D_{\bar{f}} \text{ sägs } \bar{f} \text{ vara kontinuerlig.}$
