Instängningsregeln;$\text{Antag att } h \text{ är en reellvärd funktion definierad på något intervall } ]0, \varepsilon[ \text{ där } \varepsilon > 0 \text{ och sådan att } \lim_{r \to 0^+} h(r) = 0. \text{ Om det finns } \delta > 0 \text{ sådant att } |\bar{f}(\bar{x}) - \bar{b}| \leq h(|\bar{x} - \bar{a}|) \text{ för alla } \bar{x} \in (B(\bar{a}, \delta) \cap D_{\bar{f}}) \setminus \{\bar{a}\}, \text{ då har } \bar{f} \text{ gränsvärde } \bar{b} \text{ i } \bar{a}.$
Gränsvärde längs kurva;$\text{Antag att } \bar{f} : D_{\bar{f}} \to \mathbb{R}^m \text{ (} D_{\bar{f}} \subset \mathbb{R}^n \text{), } \bar{a} \text{ är en hopningspunkt till } D_{\bar{f}} \text{ och att } \bar{f} \text{ har gränsvärde } \bar{b} \text{ i } \bar{a}. \text{ Om } \bar{r} : [c, d] \to D_{\bar{f}} \cup \{\bar{a}\} \text{ är en kontinuerlig parameterkurva sådan att } \bar{r}(c) = \bar{a}, \text{ och } \bar{r}(t) \in D_{\bar{f}} \setminus \{\bar{a}\} \text{ om } c < t \leq d, \text{ då gäller } \lim_{t \to c^+} \bar{f}(\bar{r}(t)) = \bar{b}.$
Räkneregler för gränsvärden;$\text{Antag att } \bar{f} \text{ och } \bar{g} \text{ är funktioner av } n \text{ variabler som tar värden i } \mathbb{R}^m, \text{ där } \lim_{\bar{x} \to \bar{a}} \bar{f}(\bar{x}) = \bar{b}_1 \text{ och } \lim_{\bar{x} \to \bar{a}} \bar{g}(\bar{x}) = \bar{b}_2, \text{ då gäller: (a) } \lim_{\bar{x} \to \bar{a}} (\alpha \bar{f}(\bar{x}) + \beta \bar{g}(\bar{x})) = \alpha \bar{b}_1 + \beta \bar{b}_2 \text{ för alla } \alpha, \beta \in \mathbb{R}, \text{ (b) } \lim_{\bar{x} \to \bar{a}} \bar{f}(\bar{x}) \bullet \bar{g}(\bar{x}) = \bar{b}_1 \bullet \bar{b}_2, \text{ (c) Om } m=1 \text{ och } \bar{b}_2 \neq 0 \text{ gäller } \lim_{\bar{x} \to \bar{a}} \frac{\bar{f}(\bar{x})}{\bar{g}(\bar{x})} = \frac{\bar{b}_1}{\bar{b}_2}.$
Gränsvärde för sammansatt funktion;$\text{Antag att } \bar{f} : D_{\bar{f}} \to \mathbb{R}^m \text{ och } \bar{g} : D_{\bar{g}} \to \mathbb{R}^k, \text{ } \bar{a} \text{ och } \bar{b} \text{ är hopningspunkter till } D_{\bar{f}} \text{ respektive } D_{\bar{g}} \text{ och dessa uppfyller: (a) } \bar{f}(\bar{x}) \to \bar{b} \text{ då } \bar{x} \to \bar{a} \text{ och } \bar{g}(\bar{y}) \to \bar{c} \text{ då } \bar{y} \to \bar{b}, \text{ (b) det finns ett öppet klot } B(\bar{a}, \varepsilon) \text{ sådant att } \bar{f}(\bar{x}) \neq \bar{b} \text{ om } \bar{x} \in (B(\bar{a}, \varepsilon) \cap D_{\bar{f}}) \setminus \{\bar{a}\}, \text{ (c) det finns punkter } \bar{x} \neq \bar{a} \text{ godtyckligt nära } \bar{a} \text{ sådana att } \bar{g}(\bar{f}(\bar{x})) \text{ är definierat. Då gäller att } \bar{g}(\bar{f}(\bar{x})) \to \bar{c} \text{ då } \bar{x} \to \bar{a}.$
Komponentvis gränsvärde;$\text{Om } \bar{f} = (f_1, f_2, \dots, f_m) : D_{\bar{f}} \to \mathbb{R}^m \text{ då gäller } \lim_{\bar{x} \to \bar{a}} \bar{f}(\bar{x}) = \bar{y} = (y_1, y_2, \dots, y_m) \text{ om och endast om } \lim_{\bar{x} \to \bar{a}} f_j(\bar{x}) = y_j \text{ för varje } 1 \leq j \leq m.$
Kontinuitet för sammansatt funktion;$\text{Om } \bar{f} \text{ är kontinuerlig i } \bar{a} \text{ och } \bar{g} \text{ är kontinuerlig i } \bar{f}(\bar{a}), \text{ i så fall är den sammansatta funktionen } \bar{g} \circ \bar{f} \text{ definierad via } (\bar{g} \circ \bar{f})(\bar{x}) := \bar{g}(\bar{f}(\bar{x})), \text{ kontinuerlig i } \bar{a}.$
Algebraiska egenskaper för kontinuerliga funktioner;$\text{Om } f, g : M \to \mathbb{R} \text{ är kontinuerliga så gäller: (1) } kf : M \to \mathbb{R} \text{ är kontinuerlig för alla } k \in \mathbb{R}, \text{ (2) } f + g : M \to \mathbb{R} \text{ är kontinuerlig, (3) } f \cdot g : M \to \mathbb{R} \text{ är kontinuerlig, (4) } f/g : M \setminus \{\bar{x} \in M : g(\bar{x}) = 0\} \to \mathbb{R} \text{ är kontinuerlig.}$
